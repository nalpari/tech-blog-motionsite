## Claude Code 전문가를 만드는 잘 알려지지 않은 12가지 명령어

### 서문

인기가 없지만 Claude Code 전문가가 될 수 있는 관문이 되는 Claude Code 명령어들이 있다고 말한다면 어떨까요?

하지만 이러한 명령어들을 최대한 활용하려면 작동 방식을 이해해야 합니다. 그렇지 않으면 악몽이 될 수도 있습니다.

빠르게 떠오르는 예시는 `--dangerously-skip-permissions`입니다. 워크플로우 간소화에는 매우 유용하지만, 신중하게 사용해야 합니다. 잘못 사용하면 심각한 문제에 빠질 수 있습니다.

하지만 이러한 명령어들이 바로 캐주얼 Claude Code 사용자와 파워 사용자를 구분하는 요소입니다. AI 제안을 복사-붙여넣기하는 것과 당신의 워크플로우를 **이해하는** AI 팀원을 갖는 것의 차이입니다.

### 12가지 강력한 Claude Code 명령어

## 1. `-dangerously-skip-permissions`

**기능**: 모든 권한 프롬프트를 우회하여 파일 편집이나 명령 실행에 대한 승인 없이 Claude가 자율적으로 작업할 수 있게 합니다.

**마법 같은 효과**: "이 전체 모듈을 리팩토링해"라고 Claude에게 말하고 실제로 커피를 마시러 갔다가 돌아와도 47번째 "이 파일을 편집해도 될까요?"에 막혀있지 않은 모습을 상상해보세요.

**위험성**: 이름에서 알 수 있듯이 위험합니다. Claude가 감독 없이 파괴적인 명령을 실행하거나 전체 코드베이스에 원치 않는 변경을 할 수 있습니다.

**사용 시점**: 중요하지 않은 프로젝트에서 작업하고, 좋은 git 관리 습관이 있으며, Claude의 판단을 신뢰할 때. 프로덕션 코드나 Claude의 제안된 변경사항이 확실하지 않을 때는 절대 사용하지 마세요.

**프로 팁**: 세션을 `Command+C`로 시작한 다음 `claude --dangerously-skip-permissions`를 실행하여 자율 코딩 경험을 즐기세요.

---

## 2. `/context`: 토큰 탐정

**기능**: MCP 도구, 사용자 지정 에이전트, 메모리 파일에서 토큰 분해를 자세히 제공하여 Claude Code 성능을 최적화합니다.

**마법 같은 효과**: Claude가 느리게 작동하거나 짧은 응답을 제공하는 이유가 궁금했나요? 이 명령어는 토큰이 어디로 가는지 정확히 보여줍니다 - 부풀어진 CLAUDE.md 파일, 과도한 대화 기록, 메모리를 많이 사용하는 서브 에이전트 때문인지.

**위험성**: 정보 과부하 - 코딩보다 토큰 사용 최적화에 더 많은 시간을 소비할 수 있습니다.

**사용 시점**: Claude가 느리게 느껴지거나, 토큰 한계에 도달하거나, 최대 효율성을 위해 설정을 최적화하고 싶을 때.

---

## 3. `/agents`: 개인 AI 군대

**기능**: 코드 리뷰, 테스팅, 문서화와 같은 특정 작업을 위해 자체 지침, 컨텍스트 창, 도구 권한을 가진 전문 서브 에이전트를 생성합니다.

**마법 같은 효과**: 모든 것을 시도하는 하나의 Claude 대신, 전문 팀을 얻습니다. 코드 리뷰어 에이전트는 순수하게 품질에 집중하고, 테스트 엔지니어 에이전트는 엣지 케이스만 생각하며, 문서 작성자 에이전트는 코드를 읽기 쉽게 만듭니다.

**위험성**: 에이전트 확산 - 너무 많은 전문 에이전트는 상충하는 조언과 컨텍스트 분편화로 이어질 수 있습니다.

**사용 시점**: 다양한 관점이 필요한 복잡한 프로젝트에서 작업하거나 AI 워크플로우에서 관심사 분리를 유지하고 싶을 때.

**프로 팁**: 최대 2-3개의 에이전트로 시작하세요. 양보다 질이 항상 승리합니다.

---

## 4. `/install-github-app`: 자동화된 PR 리뷰어

**기능**: Claude가 풀 리퀘스트를 자동으로 리뷰하도록 설정합니다.

**마법 같은 효과**: AI 도구를 더 많이 사용하면 PR 볼륨이 극적으로 증가합니다. 이 명령어는 인간 리뷰어를 소진시키지 않으면서 모든 PR이 일관되고 철저한 리뷰를 받도록 보장합니다.

**위험성**: AI 리뷰에 과도하게 의존하면 인간의 직관이 필요한 미묘한 문제를 놓칠 수 있습니다.

**사용 시점**: 매일 여러 PR을 푸시하고 일관된 리뷰 커버리지가 필요할 때, 특히 개인 프로젝트나 소규모 팀에서.

---

## 5. `-output-format json`: 자동화 게이트웨이

**기능**: Claude의 응답을 스크립팅 및 자동화 워크플로우를 위해 기계가 읽을 수 있게 만듭니다.

**마법 같은 효과**: Claude Code를 파이프라인의 다른 도구와 연결합니다. 응답을 파싱하고, 다른 시스템에 공급하거나, 복잡한 자동화 워크플로우를 구축할 수 있습니다.

**위험성**: 핵심 개발 작업에 집중하는 대신 자동화 과도 엔지니어링에 빠질 수 있습니다.

**사용 시점**: CI/CD 통합을 구축하거나, 사용자 지정 도구를 만들거나, Claude의 출력을 처리해야 할 때.

---

## 6. `/vim`: 모달 워리어를 위한

**기능**: Claude Code 내에서 vim 스타일 편집을 활성화합니다.

**마법 같은 효과**: 모달 편집의 힘과 효율성을 AI 대화에 가져옵니다. vim 키바인딩으로 탐색하고 편집할 수 있습니다.

**위험성**: vim 학습 곡선이 여기서도 적용됩니다. 이미 vim 사용자가 아니라면 속도를 높이기보다는 늦출 수 있습니다.

**사용 시점**: AI 도구에서도 모달 편집 없이는 기능할 수 없는 vim 파워 사용자일 때.

---

## 7. `-mcp-debug`: 통합 속삭이는 자

**기능**: MCP(Model Context Protocol) 구성 문제에 대한 상세한 디버깅 정보를 표시합니다.

**마법 같은 효과**: 외부 통합이 작동하지 않고 이유를 파악할 수 없을 때, 이 플래그는 무대 뒤에서 무슨 일이 일어나는지 보여줍니다.

**위험성**: 디버그 출력은 압도적일 수 있고 로그에서 민감한 구성 세부사항을 노출할 수 있습니다.

**사용 시점**: Jira, Google Drive 또는 사용자 지정 API와 같은 도구로 복잡한 MCP 통합을 설정할 때.

---

## 8. `!` 명령 접두사: 토큰 절약자

**기능**: 직접 셸 명령 실행을 위해 Claude의 대화 모드를 우회합니다.

**마법 같은 효과**: Claude가 모든 명령을 해석하고 설명하는 대신 그냥 실행합니다. 토큰을 절약하고 더 빠른 결과를 얻습니다.

**위험성**: 명령이 무엇을 하는지에 대한 컨텍스트가 적어서 혼란이나 예상치 못한 결과로 이어질 수 있습니다.

**사용 시점**: 실행하고 싶은 명령을 정확히 알고 있고 Claude의 해석이나 설명이 필요하지 않을 때.

**예시**: "git 상태를 확인해줄 수 있나요?" 대신 `!git status`

---

## 9. `/compact` vs `/clear`: 전략적 메모리 관리

**기능**: `/compact`는 대화 기록을 요약하고 `/clear`는 완전히 새로운 시작을 제공합니다.

**마법 같은 효과**: 전략적 컨텍스트 관리로 불필요한 세부사항을 제거하면서 관련 정보를 유지할 수 있습니다. AI 대화를 위한 마리 콘도라고 생각하세요.

**위험성**: 압축하면 중요한 뉘앙스를 잃을 수 있고, 지우면 모든 컨텍스트를 잃습니다.

**사용 시점**: 대화가 다루기 힘들어지지만 모든 컨텍스트를 잃고 싶지 않을 때(`/compact`), 또는 완전히 다른 작업을 시작할 때(`/clear`).

---

## 10. `$CLAUDE_PROJECT_DIR`를 사용한 사용자 지정 후크: 자동화 닌자

**기능**: 프로젝트 디렉토리 환경 변수에 액세스하여 도구 실행 전/후에 명령을 자동으로 실행합니다.

**마법 같은 효과**: Claude가 변경할 때마다 코드 포맷팅, 테스트 실행, 문서 업데이트 또는 보안 검사를 자동으로 수행하는 워크플로우를 설정합니다.

**위험성**: 후크가 Claude의 워크플로우를 늦추거나 예상치 못하게 실패하여 개발 흐름을 깨뜨릴 수 있습니다.

**사용 시점**: 코드 포맷팅, 린팅 또는 자동화된 테스팅과 같은 일관된 후처리 요구사항이 있을 때.

**예시**: Claude가 Python 파일을 수정한 후 자동으로 포맷팅.

---

## 11. Shift+드래그 파일 참조: 컨텍스트 마스터

**기능**: 파일을 드래그할 때 Shift를 누르고 있으면 새 탭에서 열지 않고 Claude에서 제대로 참조됩니다.

**마법 같은 효과**: 열린 탭으로 작업 공간을 어수선하게 만들지 않고 대화에 파일 컨텍스트를 원활하게 추가합니다.

**위험성**: Shift 키를 누르는 것을 쉽게 잊고 원치 않는 열린 파일들로 가득 찬 작업 공간이 될 수 있습니다.

**사용 시점**: Claude와의 대화에서 여러 파일을 참조해야 할 때.

---

## 12. 더블 이스케이프 메시지 탐색: 시간 여행자

**기능**: Escape를 두 번 누르면 대화에서 되돌아갈 수 있는 모든 이전 메시지 목록을 보여줍니다.

**마법 같은 효과**: 모든 것을 스크롤하지 않고 대화 기록의 어떤 지점으로든 빠르게 탐색할 수 있습니다.

**위험성**: 주의를 산만하게 하고 현재 작업에서 벗어나게 할 수 있습니다.

**사용 시점**: Claude가 앞서 말한 것을 참조하거나 이전 지점에서 대화를 분기시키고 싶을 때.

## 진정한 마법: 명령어 조합하기

진정한 힘은 이러한 명령어를 개별적으로 사용하는 것이 아니라 전략적 조합에 있습니다.

다음은 시너지 효과를 보여주는 실제 워크플로우입니다:

1. 자율 작업을 위해 `-dangerously-skip-permissions`로 시작
2. `/agents`를 사용하여 전문 리뷰어 설정
3. 자동 포맷팅을 위한 사용자 지정 후크 활용
4. 토큰 사용량 모니터링을 위해 `/context` 사용
5. 직접 명령 실행을 위해 `!` 접두사 적용
6. 컨텍스트를 유지하기 위해 전략적으로 `/compact` 사용
